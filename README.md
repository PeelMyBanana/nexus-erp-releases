# Nexus ERP — downloads

This repository only hosts the **installers and automatic updates** for Nexus ERP. The source code is private.

## Install
1. Open the [latest release](../../releases/latest).
2. Download **`Nexus.ERP_x.y.z_x64-setup.exe`** and run it.
   *If Windows shows "Windows protected your PC", click **More info → Run anyway**. The installer isn't code-signed with a paid certificate.*
3. Sign in with the account your administrator gave you.

## Updates
Once installed, the app checks for new versions on its own and shows **Update available → Install & restart**. Every update is signed, and the app refuses any update that isn't.
